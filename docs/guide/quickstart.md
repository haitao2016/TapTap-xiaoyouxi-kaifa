# 快速开始

## 创建新项目

1. 打开 TapDev Studio
2. 点击「新建项目」按钮
3. 在桌面端选择项目目录
4. 等待项目创建完成后进入编辑器

当前工作台会创建一个默认的 Unity 项目；项目名称和模板不会在此流程中单独弹窗配置。

## 打开现有项目

1. 点击「打开项目」按钮
2. 选择项目目录
3. TapDev Studio 会打开所选项目并进入编辑器

## 基本操作

### 编辑代码

- 使用左侧文件树浏览项目文件
- 点击文件在编辑器中打开
- 支持语法高亮、代码补全、多光标编辑

### 构建项目

1. 从左侧导航栏打开「构建」页面
2. 配置构建参数：
   - 目标平台（WebGL、Android、iOS）
   - 版本号
   - 压缩打包、WASM 分包、资源优化和移除调试信息
3. 点击「开始构建」；Web 模式下该按钮显示为「模拟构建」，Android/iOS 构建需要 Electron 桌面端

### 调试游戏

1. 从左侧导航栏打开「调试」页面
2. 点击「启动调试服务器」
3. 设置断点（点击行号）
4. 使用调试面板查看变量和调用堆栈

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+S` | 保存文件 |
| `Shift+Alt+F` | 格式化当前文件 |
| `Ctrl+D` | 添加当前单词的多光标选择 |
| `Ctrl+Shift+P` | 打开代码片段面板 |
| `Ctrl+空格` | 打开代码片段面板 |
| `Esc` | 关闭代码片段面板 |
